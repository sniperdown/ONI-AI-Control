## 二、IL 层面的发现（`BuildTool.TryBuild(int cell)`）

开头三条 early-return，**逐条都有实际意义**：

```
+00  if (visualizer == null) return;
     → 预览对象必须存在（Activate(def, mats) 之后就有了）

+0F  if (cell == lastDragCell && buildingOrientation == lastDragOrientation) return;
     → ★ 去重：把 lastDragCell 设成"目标格"反而会触发它直接返回
       （我们试过三种组合，反而越设越糟）

+27  if (Grid.PosToCell(visualizer.transform.position) != cell) → 跳过整段建造
     → ★★ 真正的门槛：它用【visualizer 的位置】算 cell 再比对，
        参数 cell 本身不是判据
```

**⇒ 要让 `TryBuild` 干活，必须先 `visualizer.transform.position = Grid.CellToPos(cell)`。**
这一条是 0.55.0 加的 `setFields:"visualizerPos"`，**实测生效**（截图能看到"建造氧气扩散器 / 点击以建造"的提示框）。

**再往后**（+65 起）：
```
lastDragCell = cell
ClearTilePreview
facadeID → PlanScreen.LastSelectedBuildingFacade
DebugHandler.InstantBuildMode || (SandboxModeActive && InstantBuild) 二选一
→ 真正的建造分支
→ PostProcessBuild(instantBuild, pos, builtItem)
```

## 三、卡点：`PlanScreen.Instance` 为 null

**异常栈（0.56.0 实测）**：
```
System.NullReferenceException
  at PlanScreen.GetBuildingPriority ()
  at BuildTool.PostProcessBuild (Boolean instantBuild, Vector3 pos, GameObject builtItem)
  at BuildTool.TryBuild (Int32 cell)
```

**关键事实**：
1. `PostProcessBuild` 的参数里有 `builtItem` ⇒ **对象已经造出来了**，炸在"设置优先级"；
2. 但最终**没留下建筑**（异常打断了后续注册/落地）；
3. **`PlanScreen.Instance` 是 private setter 的静态属性**，只在 `OnPrefabInit()` / `OnSpawn()` 里被赋值。

**⇒ 它只在"Plan 界面这个 KScreen 被创建"时才存在。**

**我们试过但无效的做法**：
- 用鼠标点底部「氧气」分类 ⇒ 面板确实弹出来了（左边能看到制氧机/电解器/铁锈脱氧机）
- **但 `PlanScreen buttons` 仍然是 0，`TryBuild` 仍然空引用**

**原因**：底部那排分类栏属于 **`BuildMenu`（`BuildMenuCategoriesScreen`）**，**不是 `PlanScreen`**。
`PlanScreen` 需要走 `KScreenManager.StartScreen(prefab, ...)` 才有，而我们手上没有那个 prefab 引用。

## 四、材料：`DefaultElements()` 给错了

画面上显示 **「钾矿 0 千克 / 200 千克」**，但氧气扩散器应该吃**藻类（Algae）**，而库存里 Algae 有 545 千克。

⇒ `def.DefaultElements()` 返回的很可能是它 `MaterialCategory` 里的**默认项**（Kyanite / 钾矿），不是真正的建造材料。

**0.58.0 加了 `materials` 参数**（显式指定，如 `"materials":["Algae"]`），并输出 `materialsDiag` 便于对照。**尚未验证。**

## 五、位置要求

`MineralDeoxidizer`（氧气扩散器）的 `IsValidPlaceLocation` 有两条：
1. **必须建在未占用的空间中**（`validateOnly` 能查到）；
2. **周围必须是可呼吸气体**（`validateOnly` **查不到**，只有真建造时才暴露 —— 画面显示"所需气体不可呼吸"）。

**⇒ 挑位置要用两步**：
```
① validateOnly:true 看地形（valid/reason）
② GET /v1/env?x=&y=&r=1 看那格气体（breathablePct 高、氧气占多数）
```
**实测数据**：卡塔莉娜 `(110,217)` 周围 r=3 可呼吸 100%；`(109,220)` / `(108,220)` 地形合法。

## 七、这轮踩过的坑（通用）

- **dump 的可见性不可信**（第 5 次）：`BuildTool.OnDragTool` dump 说 public，编译器报 **CS0122 protected**；`TryBuild` 是 private。
- **反射 ≠ 相信 dump**：反射是运行时查方法，`GetMethod` 返回 null 会**明确报错**，不会静默。
- **错误文案写死会骗人**：0.58.0 把 `placeMode` 写死在错误消息里，导致 `instant` 被误读成 `defbuild`。**错误消息里的变量必须动态拼接。**
- **刚加载存档时 `operational` 不可信**：跑几秒才会初始化，别急着判"设备坏了"。
- **全图环境平均没有诊断价值**：气体不混杂、各占一格、远近不互通 ⇒ 必须框选小人活动区域看 `breathablePct`。
- **`cell` 是整张 Grid 的线性下标**（多星球并排），不是单星球尺寸 ⇒ 一律用 `dupes[].x/y`，别自己 `% width`。
