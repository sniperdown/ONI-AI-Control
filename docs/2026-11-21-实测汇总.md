## 1. 判据切换（0.113.0，已装已验证）

`/v1/reach` 的 `reachable` 现在取**游戏自己的 `Navigator.CanReach`**（任一小人可达即可）：

- 新增 `judge` 字段：`Navigator.CanReach` / `bfs-fallback`（没有复制人时才降级）
- 原 BFS 结论保留在 `bfsReachable`
- `reason` 只在 `bfs-fallback` 时有意义；游戏说能到时为 `null`
- `dig` / `build` 响应里的 `reach` 标注同样换成了游戏判据（`unreachable` 计数按新口径）

**为什么换**（实测两类错，两个方向都有）：

| 类型 | 例子 | 我们的 BFS | 游戏 |
|---|---|---|---|
| 漏判（游戏能到） | 对角斜通道（泥巴区 83 个空气格里 14 格）、跨 1 格缺口、爬 2 格陡坎 | F | **T** |
| 误判（我们说能到） | 梯子顶被天花板压住 `(116,212)`；挖开自己但**头顶仍是实心**的 `(113,220)` | T | **F** |

⇒ **根因**：自研 BFS 只走四邻域、且**没考虑复制人占 2 格高（头顶也要空）**。
`bfs-fallback` 路径还欠一条"本格与上一格都必须非实心"的修正（未做）。

## 2. 建造

| 情形 | 结果 |
|---|---|
| `placeMode` 合法值 | `trybuild` / `instant` / `defbuild` / `dragtool`（别的值报 `BAD_REQUEST` 并列出这四个） |
| **沙盒开启时 `trybuild`** | **也会瞬间建成**（`uc=false`、不产生施工任务、不扣材料）—— 想测"小人真去施工"必须先关沙盒 |
| `instant` | 非沙盒档被闸门挡（`Gate.CheatsUnlocked`）；沙盒档返回 `jobState:"cheat-instant"`、`materialsConsumed:false` |
| `defbuild` | `jobState:"cheat-spawned"`（同样是作弊路径） |
| 材料不足（Ceramic，档里 0 kg） | **照样放蓝图**：`placed=true, enough=false, total=0, hint="enough 仅供参考，不参与放行"` |
| 天花板类建筑（CeilingLight）放在没有天花板处 | `NOT_PLACED`："调用完成但请求格 ±1 范围内没有在建对象" —— **诚实报错，没假装成功** |
| 悬空放 Tile（下方无物块） | `buildable=true` —— **不是 bug**：物块本来不需要支撑 |
| 有地基的 Tile 蓝图 | `placed=true, uc=true` |

### `placed:true` ≠ 会建成（这条最容易被 AI 误读）

实测：平台上方 1 格（`y=211`，脚下 `y=210` 是走道）的 4 个 Tile 蓝图**全部被建成**；
平台外 `(136,214)` 的孤立蓝图**一直没人来**，小人全程 `IdleChore`。

⇒ 判据：**蓝图要被建成，必须有"小人能站到、且与蓝图相邻"的格子**。`placed:true` 只代表草图放下去了。

## 4. 液体锁（梯子右侧，`x=116..118 / y=224..225`）

结构：每格 **0.01 kg 油膜**（`CrudeOil` 在上、`Petroleum` 在下），中间 `(117,224/225)` 是**真空**，
上下被 `SuperInsulator` 封住。

30 秒实测（运行前 → 运行后）：

| 位置 | 气体 | 变化 |
|---|---|---|
| 锁左 `(115,224)` | Oxygen 2.004 → 1.988 kg | −0.016 |
| 锁右 `(119,224)` | Oxygen 2.154 → 2.107 kg | −0.047 |
| 锁体 `(116,224)`、`(118,224)` | CrudeOil 0.01 kg | **0 变化** |
| 中间 `(117,224)` | Vacuum 0 kg | **0 变化** |

侧面温差 **左 299.4 K / 右 373.1 K（差 74 K）**，30 秒不收敛。

⇒ **0.01 kg 油膜 + 中间真空，同时隔绝气体与热量**；`/v1/map` 的 `element/mass/temperature`
三个通道足够验证它，不需要新接口。

（用户补充的机制背景：温度传递取决于相邻物块导热系数；隔热砖本身很低、仍会缓慢漏温；
双层则两侧接触面都几乎为零，可视为完全不导热。**不需要再测**。）

## 5. 接口细节（踩过才知道）

- `/v1/map` 通道只有三个：`element` / `mass` / `temperature`；**没有气体成分百分比通道**
- `/v1/map` 单次硬上限 **64×64 格（4096）**，超了报 `BBOX_TOO_LARGE`；`stride` 不改变这个上限
- 视野迷雾开着时，未探索区读不到元素
- `/v1/env` 的区域参数是 **`x, y, w, h`**（`?x=99&y=199&w=15&h=6`）；`bbox=` / `region=` 都不认，会退回 whole-visible
- `/v1/elements?tag=` 能读 `thermalConductivity` / `specificHeatCapacity` / `state`
- `/v1/saves` 的 `cycle` 来自 `.sav` 头 `numberOfCycles`，**比游戏内 cycle 少 1**
- 梯子格在 `/v1/reach` 里就是普通可达格（**梯子顶 = 平地**）；`LadderFast` / `FirePole` 都算

## 6. 操作纪律（血的教训）

**装 DLL 要重启游戏 = 丢弃玩家所有未保存改动。** 本轮我为了装 0.113.0 重启，
把用户刚搭好的泥巴斜通道整个弄丢了（回到保存点时那里是实心 Dirt）。

⇒ 规矩：**重启/装 DLL 前必须先问"现在有没有未保存的东西"，不许默认"反正只是测试档"**。
建议写进 `SAVE-LOAD-RULES.md`。

## 8. 沙盒模式下的边界（15:59 实测，mod 0.114.1）

| 动作 | 沙盒 ON 时的行为 | 证据 |
|---|---|---|
| `build` `trybuild` | **瞬间建成** `jobState=completed, uc=false` | 不用小人、不用等 |
| `dig` | **仍是挂标记**（元素保持 `Dirt`） | 与玩家描述一致 |
| `deconstruct` | **仍是挂标记** `jobState=marked` | 同上 |
| `cancel` | **仍走销毁标记物** `modes=destroy:` `pendingFrame=true` | 标记机制不受沙盒影响 |
| 「摧毁」 | **独立工具** `SandboxDestroyerTool`，底层只有一句 `GameUtil.DestroyCell(cell, ?, ?, ?)`（**4 个参数**，类型待定） | `OnPaintCell` 的 IL |

**bug（本轮发现，未修）**：沙盒下 `build` 返回 `materialsConsumed=true`，但库存实测没变
（`onGround` 建前建后都是 11200 kg）。原因是判定口径用了"是否走作弊路径"，
没覆盖"沙盒把 trybuild 也变成瞬建"这条分支。
修法：`underConstruction==false` 的瞬建一律报 `false`。

**语义澄清**：`deconstruct`（派活给人拆，要人等）与「摧毁」（沙盒专用、立即抹掉、无任务无小人）
是两件事，不要混用；后者若接成接口必须挂作弊闸门。
